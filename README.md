## About
This is an initial project for a website for a junior company linked to the Federal University of Pará, Campus Castanhal. Contains all information about the services offered by the company, as well as the roles and responsibilities of its employees.
## Getting Started
### Cloning
How to clone your project
Type in your Git or PowerShell terminal
```
git clone https://github.com/linkjr-castanhal/linkjr.git
```
To install project dependencies, run it in your code editor
```bash
npm install
```
To execute it type
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
## Prerequisites
npm or pnpm installed
Node js installed
git installed
