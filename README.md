## 📋 Project Overview
This is an initial project for a website for a junior company linked to the Federal University of Pará, Campus Castanhal. Contains all information about the services offered by the company, as well as the roles and responsibilities of its employees.

## 📦 Project setup

#### 1. Clone the repo to your local environment

```bash
git clone https://github.com/linkjr-castanhal/linkjr.git
```

#### 2. Open the project folder
```bash
cd linkjr
```

#### 3. Install the project dependencies

```bash
pnpm install
```

#### 4. Run your development server
```bash
pnpm dev
# or
yarn dev
```

#### 5. On your browser, open the localhost on http://localhost:3000

## 🚀 How to contribute 

Before doing your changes on the project, create a new branch from the `dev` branch:

```bash
git checkout -b feature/LNK-X/NAME
```
After commiting and pushing all of your changes, open a Pull Request to the `dev` branch, using and filling the PR template. At the end,set someone to **review** your PR, if needed.
